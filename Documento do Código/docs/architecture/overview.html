🎯 1. Visão Geral do Projeto

MatchJobs é uma plataforma completa de recrutamento e seleção que conecta candidatos e empresas de forma inteligente. O sistema oferece funcionalidades avançadas para gestão de candidaturas, análise comportamental com IA, e um processo seletivo estruturado.

🎨 Tecnologias Utilizadas

Next.js 14 React 18 TypeScript Tailwind CSS shadcn/ui Lucide Icons LocalStorage Gemini AI

🔥 Características Principais

🧠 Análise Comportamental com IA

Sistema avançado de análise psicológica usando Gemini AI, incluindo Big Five e Eneagrama.

👤 Perfis Dinâmicos

Perfis completos para candidatos e empresas com dados estruturados e validação.

📋 Gestão de Vagas

Sistema completo de criação, edição e gestão de vagas com etapas personalizáveis.

🔄 Processo Seletivo

Fluxo estruturado de candidaturas com etapas, avaliações e movimentação de candidatos.

🏗️ 2. Arquitetura do Sistema

📊 Arquitetura Geral

O MatchJobs segue uma arquitetura moderna baseada em componentes React com Next.js, utilizando localStorage para persistência de dados e integração com IA para análises comportamentais.

🔧 Camadas do Sistema

Camada Responsabilidade Tecnologias
Apresentação Interface do usuário, componentes visuais React, Next.js, Tailwind CSS, shadcn/ui
Lógica de Negócio Regras de negócio, validações, fluxos TypeScript, React Hooks
Dados Persistência, storage, estado LocalStorage, JSON, Context API
Integração APIs externas, IA, serviços Gemini AI, Fetch API

🎨 Padrões de Design

  • Component-Based Architecture: Componentes reutilizáveis e modulares
  • Separation of Concerns: Separação clara entre lógica e apresentação
  • Single Responsibility: Cada função tem uma responsabilidade específica
  • DRY (Don't Repeat Yourself): Reutilização de código e componentes

🔐 5. Sistema de Autenticação

🎯 Funcionalidades de Autenticação

📝 Cadastro de Usuários

O sistema suporta dois tipos de usuários:

  • Candidatos: Identificados por CPF com validação completa
  • Empresas: Identificadas por CNPJ com validação completa

🔑 Processo de Login

  1. Usuário insere email e senha
  2. Sistema valida credenciais no localStorage
  3. Cria sessão do usuário
  4. Redireciona para dashboard apropriado

🚀 9. Como Usar o Sistema

🎯 Primeiros Passos

✅ Instalação e Execução

  1. Clone o repositório
  2. Execute npm install
  3. Execute npm run dev
  4. Acesse http://localhost:3000

👤 Fluxo do Candidato

  1. Cadastro: Acesse /auth/register e selecione "Candidato"
  2. Login: Faça login com suas credenciais
  3. Perfil: Complete seu perfil em /dashboard/candidate/profile/edit
  4. Análise: Faça a análise comportamental em /dashboard/candidate/analysis/edit
  5. Candidaturas: Aplique para vagas e acompanhe no dashboard

🏢 Fluxo da Empresa

  1. Cadastro: Acesse /auth/register e selecione "Empresa"
  2. Login: Faça login com suas credenciais
  3. Perfil: Complete o perfil da empresa
  4. Vagas: Crie vagas em /dashboard/company/jobs/edit
  5. Gestão: Gerencie candidatos e processo seletivo

🧠 Sistema de Análise Comportamental

📊 Big Five Personality

  • Abertura: Criatividade e interesse por novas experiências
  • Conscienciosidade: Organização e responsabilidade
  • Extroversão: Sociabilidade e energia
  • Amabilidade: Cooperação e confiança
  • Neuroticismo: Estabilidade emocional

🎭 Eneagrama (Tipos 1-9)

Sistema de personalidade que identifica 9 tipos diferentes com características específicas, motivações e padrões comportamentais.

💡 Insights de IA

  • Recomendações de posições ideais
  • Dicas para se destacar
  • Áreas de desenvolvimento
  • Perfil comportamental detalhado

📋 Processo Seletivo

🔄 Etapas Padrão

  1. Triagem: Análise inicial da candidatura
  2. Teste Técnico: Avaliação de habilidades técnicas
  3. Entrevista: Entrevista com RH/gestor
  4. Finalistas: Candidatos pré-selecionados

⚡ Ações Disponíveis

  • Mover Etapa: Aprovar candidato para próxima etapa
  • Desclassificar: Rejeitar candidato
  • Visualizar Perfil: Ver perfil completo do candidato
  • Adicionar Notas: Comentários sobre o candidato

⚠️ Importante - Configuração de API

Para usar a análise comportamental com IA, é necessário:

  1. Obter uma chave da API do Google Gemini
  2. Configurar a variável de ambiente GEMINI_API_KEY
  3. Garantir que a API esteja habilitada no Google Cloud Console
