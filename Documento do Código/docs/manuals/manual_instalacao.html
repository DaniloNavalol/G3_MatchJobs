💻 1. Requisitos do Sistema

Requisitos Mínimos

🖥️ Hardware

  • Processador: Dual-core 2.0 GHz ou superior
  • Memória RAM: 2GB mínimo
  • Armazenamento: 200mb de espaço livre
  • Conexão: Internet banda larga

⚙️ Software

  • Sistema Operacional: Windows 10+, macOS 10.15+, Ubuntu 18.04+
  • Node.js: Versão 18.17.0 ou superior
  • Git: Versão 2.25.0 ou superior

Verificação de Requisitos

Execute os comandos abaixo para verificar se os requisitos estão instalados:

node --version # Verificar versão do Node.js
npm --version # Verificar versão do npm
git --version # Verificar versão do Git

Ferramentas de Desenvolvimento

1 Node.js e npm: Baixe em nodejs.org (versão LTS recomendada)
2 Git: Baixe em git-scm.com
3 VS Code: Baixe em code.visualstudio.com

🚀 2. Instalação do Ambiente

Instalação por Sistema Operacional

📦 Instalação no Windows

1 Instalar Node.js:

Baixe o instalador LTS do nodejs.org

Execute o instalador e siga as instruções

Marque a opção "Add to PATH" durante a instalação

2 Instalar Git:

Baixe o Git do git-scm.com

Execute o instalador com as configurações padrão

Escolha "Git from the command line and also from 3rd-party software"

3 Configurar Git:
git config --global user.name "Seu Nome" git config --global user.email "seu.email@exemplo.com"

🍎 Instalação no macOS

1 Instalar Homebrew (recomendado):
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
2 Instalar Node.js:
# Via Homebrew (recomendado) brew install node # Ou baixar do site oficial # https://nodejs.org
3 Instalar Git:
# Via Homebrew brew install git # Ou usar o Git já incluído no Xcode Command Line Tools xcode-select --install
4 Configurar Git:
git config --global user.name "Seu Nome" git config --global user.email "seu.email@exemplo.com"

🐧 Instalação no Linux

1 Atualizar sistema:
# Ubuntu/Debian sudo apt update && sudo apt upgrade -y # CentOS/RHEL/Fedora sudo yum update -y # ou sudo dnf update -y
2 Instalar Node.js:
# Ubuntu/Debian curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - sudo apt-get install -y nodejs # CentOS/RHEL/Fedora curl -fsSL https://rpm.nodesource.com/setup_18.x | sudo bash - sudo yum install -y nodejs
3 Instalar Git:
# Ubuntu/Debian sudo apt install git -y # CentOS/RHEL/Fedora sudo yum install git -y
4 Configurar Git:
git config --global user.name "Seu Nome" git config --global user.email "seu.email@exemplo.com"

📁 3. Configuração do Projeto

Clonando o Repositório

1 Clone o repositório:
https://github.com/DaniloNavalol/G3_MatchJobs.git
cd G3_MatchJobs/Codigo
2 Verifique a branch:
git branch git checkout main

Instalação de Dependências

1 Instalar dependências do projeto:
npm install

⚙️ 4. Configuração de Ambiente

Variáveis de Ambiente

1 Copie o arquivo de exemplo:
cp .env.example .env.local
2 Configure as variáveis necessárias:
# Configuração do Google Gemini AI
GOOGLE_GEMINI_API_KEY=sua_api_key_aqui

Configuração da API do Google Gemini

1 Acesse o Google AI Studio:

Vá para ai.google.dev

Faça login com sua conta Google

Crie um novo projeto ou use um existente

2 Gere uma API Key:

Clique em "Get API Key"

Crie uma nova API Key

Copie a chave gerada

Cole no arquivo .env.local

🔐 Segurança da API Key

Nunca commite o arquivo .env.local

Mantenha sua API Key segura e privada

Configure limites de uso no Google Cloud Console

Monitore o uso da API regularmente

🏃‍♂️ 5. Execução Local

Iniciando o Servidor de Desenvolvimento

1 Inicie o servidor:
npm run dev
2 Acesse a aplicação:

Abra o navegador

Acesse http://localhost:3000

A aplicação deve carregar normalmente

Scripts Disponíveis

📋 Scripts do Package.json

npm run dev # Inicia o servidor de desenvolvimento
npm run build # Cria build de produção
npm run start # Inicia servidor de produção
npm run lint # Executa ESLint npm run lint:fix # Corrige problemas do ESLint automaticamente
npm run type-check # Verifica tipos TypeScript

Verificação da Instalação

1 Teste as funcionalidades principais:

Navegue pela página inicial

Teste o menu responsivo

Acesse a página de cadastro

Verifique se não há erros no console do navegador

2 Teste a funcionalidade de IA:

Faça cadastro como candidato

Acesse "Editar Perfil"

Teste o upload de currículo

Verifique se a IA processa o arquivo
